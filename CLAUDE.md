# CLAUDE.md

Tweet sentiment classifier (positive / negative / neutral): NLTK preprocessing, TF-IDF features, scikit-learn logistic regression. The phased project plan lives in a Claude Doc: https://claude.ai/code/artifact/3e122dcf-f404-44b3-8c79-9f54f64eb2f4

## Commands

- Setup: `python3 -m venv .venv && .venv/bin/pip install -r requirements.txt && .venv/bin/python scripts/download_nltk_data.py`
- Tests: `.venv/bin/pytest`
- Build train/val/test split: `.venv/bin/python -m sentiment.data` (needs `data/raw/Tweets.csv` from Kaggle, downloaded by hand)

## Conventions

- Pipeline code lives in `src/sentiment/` as plain modules; notebooks only explore and import from it. The package is installed in editable mode via `-e .` in `requirements.txt`.
- Random seed is 42 everywhere.
- Tune on train/validation only. The test split is scored once, for final numbers.
- The Phase 3 baseline metrics are the reference for the precision-gain claim; never change them after tuning starts.
- Metrics go to `reports/metrics.json`, figures to `reports/figures/`.
- Dataset: Kaggle Twitter US Airline Sentiment. Don't use the OpenML copy (id 43628): it strips `@` and `#` from tweets.
- On this machine, Python downloads need certifi's CA bundle (python.org build has no certs); see `scripts/download_nltk_data.py`.
- `data/` and `models/` are git-ignored and regenerated by the pipeline.
- Pin new dependencies in `requirements.txt`.
